[자바 실행 순서]
    1. src폴더내.java 확장자에서 java 코드 작성
    2. 빌그(build) : run java 실행
    3. [컴파일]bin 폴더 내 .class 확장자 파일 (자동)생성

[주석] : // /* */ 

[용어]
    1. package : 해당 클래스가 위치한 폴더명
    2. class : 자바에서 컴파일 하는 최소의 단위 *클래스 { } 안에 코드 작성
    3. main함수 : (자바에서 코드 실행하는 흐름 =) 스레드 제공  
    4. ; 세미클론 : 코드의 한문장이 마침

[자료] : 데이터
    1. 리터럴 : 상수( true/false , 'a' , 2,)
    2. (기본)자료타입(형)
        1) boolean :  1byte , true/false
        2) char : 2byte , '' 감싼 문자1개저장   
        3) byte : 1byte , -128~127
        4) short : 2byte,  +-3만
        5) int : 4byte ,  +- 21억   *정수리터럴 기본 타입
        6) long : 8bute,  +-21억 이상, L/l
        7) float : 4byte ,  소수점 7자리표현 F/f
        8) double : 8byte,  소수점 17자리  *실수 리터럴 기본 타입
        *) String : 글자수 * 2byte , ""문자열(배열) 객체

[출력함수]
    1. System.out.print() : 출력
    2. System.out.println() : 출력 + 줄바꿈
    3. System.out.prinf( "형식문자", 자료 ) : 형식문자
    *) 이스케이프/제어 문자 : : \n \t \' \" \\
    *) 형식문자 : %s문자열  %d정수  %c문자  %f실수,  %자릿수s %-자릿수s %0자릿수s %전체자릿수.소수점자릿수f

[입력함수] : 다양한 입력방식 제공
    1) 입력객체 생성( 클래스 마다 1번씩 )
        Scanner scan = new Scanner( System.in );
    2) 입력객체 통한 입력함수( nextXXX(), 타입 주의, 여러개 next() 엔터기준으로 구분 )
        타입 변수명 = scan.nextXXX();     
    * ) .nextLine() : 개행(\n) 사용하기 때문에 앞에 다른 .nextXXX() 존재시 앞전 개행 포함
     예] .nextInt() ~ .nextLine() : nextInt() 에서 3 입력 후 엔터(개행\n) 치면 3반환되고 엔터(갱행\n) 남는다.
     -> 해결방안: .nextLine() 사이에 하나를 추가를 한다
     .next(띄어쓰기x) 문자열 [vs] .nextLine() 문자열(띄어쓰기o)

[타입변환] : 다형성, (하나의 자료/값) 다양한 형태(타입) 성질
    1) 자동타입변환 : byte -> short -> int -> long -> float -> double, 작은거 -> 큰거
    2) 강제타입변환 : double -> float -> long -> int -> short -> byte, 큰거 -> 작은거
        - 강제 타입:  (변환할 타입명)자료
    
[연산자]
    1. 산술연산자 : + - * / %
    2. 연결연산자 : + 
    3. 비교연산자 : < > <= >= == !=
    4. 논리/관계연산자 : && || !
    5. 증감연산자 : ++변수명, 변수명++, 변수명--, --변수명
    6. 대입연산자 : = , 복합대입연산자( += -= *= /= ) 
    7. 삼항연산자 : 조건 ? true : false , 중첩: 조건1 ? 참: 조건2 ? 참:거짓
    * 문자열 비교 함수 : 문자열A.equals("문자열B") 문자열A 가 문자열B 랑 같다.  
        - "유재석" == "유재석" [가능], new("유재석") == "유재석" [불가능]

[ 조건문 ] : 조건에 따른 코드 흐름 제어

    2. if( 조건 ){ 실행문; 실행문; }
    3. if( 조건 ){ }else{ }
    4. if( 조건 ){ }else if( 조건 ){ }else if( 조건 ){ }else{ }
    5. switch( 자료 ){ // 주로 break; 같이사용 **case 해당하는 부분부터 아래 코드 전부 실행.
        case 값1: 실행문;
        case 값2: 실행문;
        default: 실행문;
    } 

[ 반복문 ] : 조건에 따른 코드 반복 제어
    1. for( 초기식; 조건식; 증감식){ }
    *break; continue;
    2. while( 조건식 ){ 증감식; }
    3. for( 타입 변수명: 배열 ){ } : 향상된 for 문 
    * 배열타입이 int 이면 왼쪽 변수 타입도 int로 맞춘다.

[ 배열 ] *동일한 타입*의 여러 자료들을 *하나의* 배열 타입, 정적(고정) 타입 , 요소의 초기값 자동 할당( 정수: 0 , 실수: 0.0, 논리: false, 객체: null)
    1. 선언:  타입[ ] 변수명 = new 타입[ 길이 ]; ,  타입[ ] 변수명 = { 초기값, 초기값, 초기값 };
    2. 호출:
        1) 변수명, 배열의 주소값 반환
        2) Arrats.toString( 배열변수 ) : 배열의 요소들을 문자열로 반환
        3) 배열변수[ 인덱스 ]  : 배열내 특정한 인덱스의 요소값 반환
    3. 요소값 수정: 배열변수[인덱스] = 새로운값
       * 요소의 추가, 삭제 , 요소검색indexOf 등등 없다

[ 객체 ] 객체지향 프로그래밍
    1. 정의: 상태(멤버변수/필드/속성) 와 행위(메소드/함수) 정의 하는 것
    2. 클래스: 상태와 행위 코드로 작성(설계도)
        -> 용도: 1)설계 2)main(실행클래스) 
    3. 인스턴스: 특정 클래스 생성(new)한 객체(실체)
    4. 사용법 
        1) 클래스 생성
            - class 클래스명{ 멤버변수; 생성자; 메소드; }
            - 멤버변수: 
                타입 변수명;  *만약 초기값이 없으면 기본값*(정수:0, 실수:0.0, 논리:false, 객체:null)
                타입 변수명 = 초기값; 
        2) 인스턴스 생성
            - new 생성자명( )       * new 1개당: 인스턴스 1개 생성(즉, 메모리 주소값이 생성) * 
            - 타입 변수명 = new 생성자명( );  
        3) 인스턴스 참조
            - 객체변수명.멤버벼수명;   *  .(접급/도트)연산자: 변수가 갖는 객체의 주소로 이동(포인터)*
            * null. 불가  주소값이 없다는 뜻.   null : 변수가 null이면 이동할 주소(참조할 객체가)가 없다.
        // vs JS객체: 클래스 있는 객체 / 클래스 없는 객체
*) 객체는 변수가 참조하지 않으면 자동 사라진다.(GC)

    // 클래스생성시 주의할점:

        - src(개발자코드작성 .java ), bin(컴파일/번역코드 .class )
    첫 글자는 대문자로 시작(한글은 추천x)

    - 클래스 생성 안에서 초기값 설정 가능
