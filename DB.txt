[ 데이터베이스 ] : 여러 사람이나 여러 프로그램이 *공유*하여 사용할 수 있도록 데이터의 집합
    - 데이터베이스 서버 : MYSQL, 요청에 따라 데이터 처리하고 응답하는 프로그램/pc
    - 특징 : 실시간 접근, 동시공유, 데이터참조, 지속적인 변화 등 
    - 종류 : 1) 관계형데이터베이스(표) SQL기반  2) NOSQL 그래프
[ SQL ] : 관계형데이터베이스 데이터를 조작/제어 하기 위한 표준 문법 언어
    메타 데이터어: show ~, use ~
    1) DDL : 데이터 정의어 : create ~ , drop  데이터베이스/테이블 정의하고 변경
    2) DML : 데이터 조작어 : 테이블내 데이터들을 조작 SELECT INSERT 등등
    3) DCL : 데이터 제어어 : 데이터베이스 접근권한 / 계정관리
    4) TCL : 트랜잭션 제어어 : DML 실행 결과를 취소 / 적용

[ 메타데이터 ]
    show databases;
    use 데이터베이스명;
    describe 테이블명;

[ DDL ]
    DROP :
        drop database if exists 데이터베이스명;
        drop table if exists 테이블명;
    CREATE :
        create database 데이터베이스명;
        create table 테이블명( 필드명 타입 제약조건 );
    ALTER :
        alter table 테이블명 add 필드명 새로운타입;
        alter table 테이블명 modify 필드명 새로운타입;
        alter table 테이블명 chang 기존필드명 새로운필드명 새로운타입;
    RENAME :
        rename table 테이블명 to 새로운테이블명;
    TRUNCATE :
        truncate table 초기화테이블; 

[ 타입 ]
    정수 : tinyint, smallint, mediumint, int, bigint
    * unsigned: 부호 없는 자료(범위 2배) -128~127 -> 0 ~ 255
    실수 : float, double, decimal(문자열실수)
    날짜 : date, time, 날짜/시간 : datetime
    문자열 : char(n), varchar(n), text, longtext
     * char(3): 고정길이 3 [우][리][ ]
     * varchar(3): 가변길이 3 [우][리]
     * longtext : 대용량
    논리 : boolean(tinyint)

[ 제약조건 ]
    1. not null     : 값이 null이면 레코드 등록 불가
    2. unique       : 값이 중복이면 레코드 등록 불가
    3. defalut 기본값       : 레코드 등록시 값 생략하면 기본값 대입
    4. auto_incerment , *PK 인 경우에만 사용가능  : 레코드 등록시 자동 번호 증가
    5. constraint primaey key( PK필드명 )       : 기본키 / 식별키
    6. constraint foregin key( FK필드명 )references 참조할테이블명( PK필드명 )      : 참조키 / 외래키
     -- constraint 생략 가능

[ 참조옵션 ]
    1. on delete / update cascade;  : pk 가 삭제되면 fk 레코드도 같이 삭제
    2. on delete / update restrict; (생략시 기본값) : pk가 참조중이면삭제 불가능
    3. on delete / update set null  : pk가 삭제되면 fk 값은 null

[ DML ]
    1. INSERT into 테이블명( 필드명, 필드명) values(값, 값);
        - insert into 테이블명 valuew( 값1, 값2, 값3); :  모든필드에 갑 대입시 필드명 생략가능
        - insert into 테이블명( 필드명 ) values( 값 ),(값 ); : 2개 이상 레코드 등록
    2. SELECT 필드명 from 테이블명 where 조건
        - select * from 테이블명 : 테이블내 모든 조회
    3. update 테이블 set 필드명 = 수정할값, 필드명 = 수정할값  where 조건
    4. delete from 테이블명 where 조건 : 행을 삭제

[ 연산자 ]
    1. as : (별칭) 복잡한 필드명/테이블명 변경, 
        * 필드명 as 별칭, 테이블명 as 별칭, *주의할점: as 생략가능
    2. distinct : 조회결과 (필드값) 중복제거
    3. 산술연산자 : + - / * div몫  mod나머지
    4. 비교연산자 : =  !=  >  <  <=  >=
    5. 논리연산자 : and  or not
        * between 시작값 and 끝값,  in(값, 값, 값) 포함된거 찾을떄,
    6. null 연산자 :
        필드명 = null , 필드명 != null <불가능>
        필드명 is null,  필드명 is not null  <가능>
    7. 문자열패턴 :
        % 모든문자대응  , 김% : 김으로 시작하는 n개 글자
        _ 개수만큼 문자 대을, 김_ : 김으로 시작하는 두글자
