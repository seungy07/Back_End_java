[ 데이터베이스 ] : 여러 사람이나 여러 프로그램이 *공유*하여 사용할 수 있도록 데이터의 집합
    - 데이터베이스 서버 : MYSQL, 요청에 따라 데이터 처리하고 응답하는 프로그램/pc
    - 특징 : 실시간 접근, 동시공유, 데이터참조, 지속적인 변화 등 
    - 종류 : 1) 관계형데이터베이스(표) SQL기반  2) NOSQL 그래프
[ SQL ] : 관계형데이터베이스 데이터를 조작/제어 하기 위한 표준 문법 언어
    메타 데이터어: show ~, use ~
    1) DDL : 데이터 정의어 : create ~ , drop  데이터베이스/테이블 정의하고 변경
    2) DML : 데이터 조작어 : 테이블내 데이터들을 조작 SELECT INSERT 등등
    3) DCL : 데이터 제어어 : 데이터베이스 접근권한 / 계정관리
    4) TCL : 트랜잭션 제어어 : DML 실행 결과를 취소 / 적용
