[WAS]
Servelt 클래스 이용한 웹 프로그래밍 (http를 JAVA에서 사용할 수 있게 제공/구현하는 클래스)- 상속을 이용하여 (오버라이딩)
Apache Tomcat 라이브러리 제공 (Spring Boot WEB 내장)
포트 번호는 8080

WAS = Web Sever + Web contaniner
Web sever 정적컨텐츠 제공( 동적 컨텐츠 요청) html,js,css
Web contaniner 동적컨텐츠 제공 java, Servelt

Web Sever Architecture
[동작구조]
1. 클라이언트가 Web server에게 요청을 보냄
2. 요청이 정적이면 response 동적이면 contaniner로 보냄
3. contaniner이 Servelt에 init 인스턴스 생성(싱글톤)
